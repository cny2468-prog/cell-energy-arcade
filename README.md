# 세포 대사 브레이커

[게임 실행](https://cny2468-prog.github.io/cell-energy-arcade/)

효소·세포호흡·광합성을 배우는 모바일 세로형 벽돌깨기 게임입니다. 별도 설치 없이 브라우저에서 실행합니다.

| 단계 | 내용 | 벽돌 | 개념 문제 | 벽돌 크기 | 일반 모드 공 속도 | 일반 모드 패들 길이 |
|---|---|---:|---:|---|---:|---:|
| 1 | 효소 | 18개 | 3개 | 68×40 | 455 | 100 |
| 2 | 세포호흡 | 28개 | 4개 | 58×33 | 566 | 84 |
| 3 | 광합성 | 40개 | 5개 | 50×27 | 676 | 68 |

벽돌 6·7·8개를 깰 때마다 각각 개념 문제가 나오며, 단계별 문항은 27개 문항 은행에서 무작위로 선택됩니다.

단계 제한시간은 일반 모드 2분 30초 → 2분 → 1분 30초, 하드 모드 2분 → 1분 30초 → 1분입니다. 휴대폰에서는 점수·하트 영역을 한 줄로 줄여 게임판이 화면 대부분을 차지하도록 구성했습니다.

- 게임판 또는 아래 터치패드를 좌우로 드래그해 패들을 움직입니다. 마우스·방향키도 지원합니다.
- 아이템은 패들에 닿을 때만 적용됩니다. 초록 아이템은 받고 붉은 아이템은 피하세요.
- 멀티볼은 좋은 아이템이며, 공을 늘리는 유일한 방법입니다. 각 단계는 공 1개로 시작합니다.
- 문제 제한시간은 일반 20초, 하드 15초입니다. 오답·시간 초과는 남은 시간 8초 감소이며 공 개수는 변하지 않습니다.
- 여러 공 중 일부를 놓쳐도 목숨은 유지되고 마지막 공을 잃을 때만 목숨이 감소합니다.
- 기본 화면은 밝으며, 시작 화면 또는 게임 메뉴에서 밝게·어둡게를 선택할 수 있습니다.
- 시작 전 학번과 이름을 입력하고, 게임 종료 후 실제 학습한 최대 12문제의 응답·정답·해설을 DOCX로 다운로드합니다.

학번·이름은 현재 판과 학습 기록 파일에만 사용하며 서버로 전송하거나 브라우저 저장소에 저장하지 않습니다. 최고 점수·화면 설정·개념 노트는 현재 브라우저에 저장됩니다.

## 실행과 배포

`index.html`을 직접 열거나 정적 HTTP 서버로 실행합니다. 외부 글꼴을 사용할 수 없는 환경에서는 시스템 글꼴을 사용합니다. DOCX는 외부 라이브러리 없이 브라우저에서 생성합니다.

GitHub Pages의 `main` 브랜치 `/` 경로에서 배포합니다. 파일을 수정해 `main`에 올리면 게임에 반영됩니다.

배포할 때는 `version.json`의 `version`도 새 값으로 바꿉니다. 시작 로더가 매번 현재 버전을 확인해 같은 버전의 화면·문항·게임·DOCX 코드를 함께 불러옵니다. 이전 HTML 자체가 캐시된 브라우저는 게임 주소 뒤에 `?v=20261120-speed2`를 붙여 최신 시작 화면을 한 번 불러올 수 있습니다.

## 자료와 참고

학습 내용은 세포와 물질대사 수업 PPT의 효소·세포호흡·발효·광합성 내용을 바탕으로 새로 작성했습니다. 시험 자료는 포함하지 않았습니다. 공·아이템·점수는 게임 장치이며 실제 ATP 분자 수나 반응 속도를 뜻하지 않습니다.
